## Confirmed API shapes (probed 2026-06-05)

**PubMed E-utilities** (3 req/s no key, 10 with `NCBI_API_KEY`):
- esearch: `GET eutils.ncbi.nlm.nih.gov/entrez/eutils/esearch.fcgi?db=pubmed&term=<q>&retmax=N&retmode=json&sort=date`
  → `.esearchresult.idlist` = [pmid…].
- efetch (for title+abstract+journal+date+doi): `GET …/efetch.fcgi?db=pubmed&id=<csv pmids>&retmode=xml&rettype=abstract`
  → XML `PubmedArticleSet/PubmedArticle`: `MedlineCitation/Article/ArticleTitle`,
  `Abstract/AbstractText` (may be multiple, join), `Journal/Title`,
  `Journal/JournalIssue/PubDate` (Year/Month/Day), DOI at `PubmedData/ArticleIdList/ArticleId[@IdType="doi"]`,
  pmid at `MedlineCitation/PMID`.

**bioRxiv/medRxiv** (no key; date-range, no keyword search → filter client-side):
- `GET api.biorxiv.org/details/<server>/<from>/<to>/<cursor>` (server = biorxiv|medrxiv)
  → `.collection` = [{title, authors, doi, date, category, abstract, published, server}]. 30/page;
  paginate via cursor until `messages[0].count < 30`. `published` is a DOI string or "NA".

**Semantic Scholar** (throttles HARD without `S2_API_KEY` → returns `{message,code}` envelope):
- `GET api.semanticscholar.org/graph/v1/paper/search?query=<q>&limit=N&fields=title,abstract,year,venue,url,externalIds,publicationDate`
  header `x-api-key: <S2_API_KEY>` when set → `.data` = [{title, abstract, year, venue, url,
  externalIds:{DOI?}, publicationDate}]. On non-200 / `data` absent → return `{error}` (graceful).

**HF Hub** (optional `HF_TOKEN`):
- models: `GET huggingface.co/api/models?search=<q>&sort=trendingScore&limit=N` →
  [{id|modelId, downloads, likes}]; dataset: `…/api/datasets?…`; space: `…/api/spaces?search=<q>&sort=likes&limit=N`
  → [{id, likes, sdk}]. Link = `huggingface.co/{models|datasets|spaces}/{id}`.

## Contracts

All paper-producing adapters emit records matching the **existing `Paper`** wire shape
(unchanged): `{kind:"paper", source, topic, title, link, date_label, ts, summary, grounding}`.
`source` ∈ {`PubMed`, `Preprint`, `Semantic`}. `summary` = abstract[:180]+"…"; `grounding` =
full abstract. `ts` = epoch millis (0 if unknown). Adapters keep the P0 single-shot stdio
contract (read req JSON on stdin to EOF → one JSON obj on stdout; failures → `{error}` and exit 0).

New repo/space records (HF):
- Repo: `{kind:"model"|"dataset", name, link, downloads, likes}`
- Space: `{name, link, likes, sdk}`

### 5a — `model.rs`: add `Repo`, `Space`; extend `Feed`

```rust
pub struct Repo {
    pub kind: String,      // "model" | "dataset"

    pub likes: String,

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]

    pub link: String,
    pub likes: String,
    pub sdk: String,

```
Extend `Feed` with `#[serde(default)] pub repos: Vec<Repo>,` `#[serde(default)] pub spaces: Vec<Space>,`
(additive — keep `papers`, `errors`; `Default` derive still holds; existing literals using
`Feed::default()` or `..Default::default()` keep working — update any full `Feed{...}` literals).

### 5b — `scrape.rs`: generic typed fetch

Add a generic `fetch_records<T: DeserializeOwned>(scrapers_dir, source, op, args) -> Result<Vec<T>>`
that runs the adapter (reusing `run_adapter`’s timeout/kill_on_drop) and decodes `records` into
`Vec<T>`. Keep `fetch_papers` as `fetch_records::<Paper>`.

### 5c — `cache.rs`: disk cache, per-source TTL

```rust
pub struct Cache { root: PathBuf }
impl Cache {
    pub fn new() -> Self;                 // ~/.cache/research  ($XDG_CACHE_HOME fallback)
    pub fn get(&self, source: &str, key: &str, ttl: Duration) -> Option<serde_json::Value>;
    pub fn put(&self, source: &str, key: &str, val: &serde_json::Value);
}
```
Path `<root>/<source>/<sha-or-sanitized key>.json`; `get` returns `None` if missing or
older than `ttl` (use file mtime). Failures are non-fatal (return None / ignore). Unit-test
put→get hit, and a 0-duration TTL miss, using a temp root (add a `with_root` ctor for tests).

### 5d — `ratelimit.rs`: per-source min-interval pacer (Rust host, persistent)

Adapters are stateless (spec §5.2), so pacing lives here.
```rust
pub struct Pacer { last: tokio::sync::Mutex<HashMap<String, Instant>>, intervals: HashMap<String, Duration> }
impl Pacer {
    pub fn new() -> Self;  // PubMed 350ms (3/s; 110ms if NCBI_API_KEY set), Semantic 1100ms,
                           // bioRxiv 250ms, HF 150ms; default 200ms
    pub async fn acquire(&self, source: &str);  // sleep until last[source]+interval, then stamp now
}
```
Unit-test: two back-to-back `acquire("x")` calls span ≥ the interval (use a short test interval
via a `with_interval` ctor / injected map).

### 5e — `feed.rs`: concurrent fan-out + repos/spaces + cache + pacing

Rewrite `load` to fan out concurrently with `futures::future::join_all`:
- For each enabled topic × paper-source (HF `paper_search`, PubMed `search`, bioRxiv `search`,
  Semantic `search`): one task that `pacer.acquire(source).await`, checks `cache.get(source,key,ttl)`,
  else `fetch_records::<Paper>` + `cache.put`. TTL: papers 6h.
- Once (not per topic): HF `repo_search` + `space_search` → `feed.repos`, `feed.spaces` (TTL 12h).
- Collect all results; per-task error → `SourceError` (source-labelled); merge papers, dedup by
  title (existing helper), sort newest first.
- Signature: `load(scrapers_dir, topics, limit, cache: &Cache, pacer: &Pacer) -> Feed`.
  Provide cache+pacer from `main.rs`/`server.rs` `AppState` (add `cache: Arc<Cache>`, `pacer: Arc<Pacer>`).
- Keep `--no-cache` honored later; for now `main.rs --check` may pass a fresh `Cache`.
- Tests: keep the fixture-adapter tests working (point cache at a temp dir, fresh pacer); add a
  test that two sources merge and a failing source still yields a `SourceError` while others load.

### 5f — `server.rs` / `main.rs`: thread cache+pacer through `AppState`/handlers

`AppState` gains `cache: Arc<Cache>`, `pacer: Arc<Pacer>`; `get_feed` passes them to `feed::load`.
`main.rs` constructs one `Arc<Cache>`/`Arc<Pacer>` and shares with the server + TUI.
